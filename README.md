# T100 資料庫手冊

本目錄收錄 T100 系統各模組之資料庫手冊 PDF 檔案，共計 **74 份**（涵蓋 **37 個系統模組**，各包含一般版與 V3 版）。

## 檔案統計與命名說明

| 類別 | 編號範圍 | 檔案數 | 命名格式 |
| --- | --- | :---: | --- |
| 資料庫手冊（一般版） | `0023_2-01` ~ `0059_2-37` | 37 | `<流水號>_2-<序號>.資料庫手冊_<系統名稱>.pdf` |
| 資料庫手冊（V3 版） | `0400_6-01` ~ `0436_6-37` | 37 | `<流水號>_6-<序號>.V3_資料庫手册_<系統名稱>.pdf` |

> **備註：**
> - V3 版檔名中的「手**册**」與一般版的「手**冊**」字元不同，檢索或撰寫腳本時請留意。
> - 部分系統名稱在兩版本檔名間略有差異（例如：`POS+接口系統` / `POS接口系統`、`系統紀錄資料系統` / `系統記錄資料系統`）。
> - V3 版編號 `6-21` 至 `6-35` 之排序與一般版（`2-21` 至 `2-35`）略有調整，可透過下方對照表快速查找。
